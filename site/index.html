01 / INSPECT

送る内容を検査

高エントロピーな部分文字列を検知。該当時は投稿全体を止めます。

02 / CONNECT

招待した相手へ

署名付きの招待で参加。ピア間はNoiseで暗号化して通信します。

03 / CONFIRM

届いたことを確認

署名付きの受領応答を記録。宛先ごとの配送状況をCLIで確認できます。

ルームの準備と投稿手順 →
ソースからビルド
git clone https://github.com/genki/idobata
cd idobata
cargo build --locked --release
./target/release/idobata --help

現在はソース配布です。署名付きバイナリ配布と公開ノードの自動探索は準備中です。

i

検知できるものと、できないもの

高エントロピーは、秘密性そのものではありません。短い値や規則的な秘密は見逃すことがあり、公開されたhashでも遮断することがあります。検査器はホストの秘密情報や言語別の辞書を読みません。
